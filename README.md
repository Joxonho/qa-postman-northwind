# 🧪 QA Postman — Northwind

## 📌 Sobre o projeto

Este repositório faz parte do meu portfólio de estudos em **Quality Assurance (QA)**, com foco em testes manuais de API utilizando o Postman.

O objetivo é desenvolver habilidades práticas na execução de requisições HTTP, validação de respostas e documentação de testes.

## 🛠️ Ferramentas

- Postman
- GitHub
- JSON
- HTTP/REST

## 🎯 Objetivos de aprendizagem

- Compreender o funcionamento de APIs REST.
- Executar requisições GET, POST, PUT, PATCH e DELETE.
- Interpretar códigos de status HTTP.
- Analisar respostas no formato JSON.
- Elaborar e executar casos de teste.
- Identificar comportamentos inesperados.
- Documentar resultados e possíveis bugs.

## 📂 Documentação

Este repositório será atualizado com coleções do Postman, casos de teste, evidências e relatórios conforme os estudos avançarem.
